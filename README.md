# 숫자 퍼레이드 페스티벌 — 스테이션 학습 웹앱

늘봄 디자인 키트(`늘봄/디자인 키트/`)를 기반으로 만든 정적 웹앱입니다.
서버나 빌드 과정 없이 `index.html`을 열면 바로 동작합니다.

## 사용 방법 (교사)

1. 태블릿(패드) 브라우저로 이 앱 주소(또는 `index.html`)를 엽니다.
2. "축제 시작!" → 이 패드가 놓일 **스테이션**과 **패드 번호(1~4)**를 선택 → "지정 완료".
   - 한 스테이션에는 패드 4대를 1~4번으로 각각 지정해 주세요.
   - 지정 내용은 이 기기의 브라우저(localStorage)에 저장되어, 새로고침해도 유지됩니다.
3. 이후에는 패드마다 "스테이션 시작" 화면이 뜹니다. 모둠이 바뀔 때마다 아이가 "시작!"을 누르면 됩니다.
4. 화면 왼쪽 아래 작은 톱니바퀴(⚙)를 누르면 패드 지정을 다시 할 수 있습니다 (아이들 눈에 잘 안 띄도록 작게 배치).

## 구현 범위

- **① 숫자 방송국**: 실제로 동작합니다. 0~20 중 3개 숫자를 무작위로 듣고(TTS), 그림 주판으로 자가 확인 후 암호 조각 → 모둠 암호 조립(객관식 단어 6개 중 4개 순서대로 선택) → 뱃지까지 전체 흐름이 완성되어 있습니다.
- **② 짝꿍 광장 / ③ 열 묶음 공방 / ④ 주판 해설대 / ⑤ 오류 탐정소**: 아직 실제 미션 콘텐츠가 없는 **틀**입니다. "시작!"을 누르면 "준비 중" 안내와 함께 체험용으로 암호 조각을 바로 받을 수 있고, 이후 암호 조립→뱃지 흐름은 동일하게 동작합니다.

### 다른 스테이션 콘텐츠를 채우려면

`app.js` 맨 위 `STATIONS` 배열에서 해당 스테이션의 `ready: true`로 바꾸고,
`steps`(스테이션 시작 화면 안내문)와 `sentence`/`distractors`(암호 조각 4단어 + 헷갈리는 보기 2개)를 원하는 내용으로 바꾼 뒤,
①번처럼 `renderMission`/`renderCheck`에 해당하는 실제 미션 화면 로직을 추가하면 됩니다.
(현재 `sentence`/`distractors`는 자리표시용 예시 문장입니다.)

## 파일 구조

```
index.html   기본 뼈대, 폰트 로드
style.css    디자인 시스템(색상/버튼/카드/헤더/그림 주판 등)
app.js       상태 관리 + 모든 화면 렌더링 + 이벤트 처리
assets/      뱃지 5종 + 인트로 배경 이미지 (디자인 키트에서 복사)
```

## 기술 메모

- 프레임워크 없이 순수 HTML/CSS/JS로 작성했습니다. 빌드 단계가 없어 GitHub Pages 등 정적 호스팅에 폴더째 올리면 바로 동작합니다.
- 패드마다 서버 통신 없이 **독립적으로** 동작합니다. 모둠 암호는 아이들이 직접 소리 내어 말해 맞추는 방식이라 기기 간 동기화가 필요 없습니다.
- 숫자 읽기는 브라우저 내장 음성 합성(Web Speech API, `ko-KR`)을 사용합니다. 음성 합성을 지원하지 않는 기기에서는 화면에 숫자를 텍스트로 대신 보여줍니다.
- 화면은 1180×820 기준으로 만들어졌고, 실제 화면 크기에 맞춰 자동으로 축소/확대되어(비율 유지) 다양한 태블릿에서 레터박스 형태로 표시됩니다.
- 오래된 태블릿의 핀치 줌/더블탭 확대를 막아 키오스크처럼 쓰도록 `viewport` 설정을 해두었습니다.

## GitHub Pages 배포

1. 이 `숫자퍼레이드-웹앱` 폴더 내용을 저장소에 푸시합니다.
2. 저장소 설정 → Pages → 배포 브랜치/폴더를 지정합니다.
3. 발급된 주소를 각 패드 브라우저에서 열면 됩니다.
